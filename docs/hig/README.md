# Human Interface Guidelines — summary and link

The **Human Interface Guidelines (HIG)** are Apple’s official design system for iOS, iPadOS, macOS, tvOS, and watchOS. They define:

- **Foundations** — layout, typography, color, materials (including Liquid Glass), accessibility.
- **Patterns** — app structure, navigation, tab bars, sidebars, split views, sheets, popovers, menus, toolbars.
- **Components** — buttons, controls, lists, tables, forms, search, and more.
- **Platform-specific** guidance and input methods.

**Liquid Glass** is the new system-wide material described in the HIG; it forms a distinct functional layer for controls and navigation and adapts to focus, overlap, and context.

## Canonical source

Full HIG content lives on Apple’s site. This repo does not mirror the entire HIG; we keep a short summary here and point to the source.

- **URL:** [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)
